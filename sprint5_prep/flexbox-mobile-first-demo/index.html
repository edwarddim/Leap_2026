Flexbox & Mobile-First Development

Write the styles for the smallest screen first, then use min-width media queries to add layout as the screen grows. Flexbox is the tool that makes those layouts easy.

Desktop first (max-width)

.nav { display: flex; }

/* then UNDO it for phones */
@media (max-width: 767px) {
  .nav { flex-direction: column; }
}

Phones download desktop styles, then override them. You spend your time undoing work.

Mobile first (min-width)

/* base = phone: stacked */
.nav { display: flex;
       flex-direction: column; }

/* ADD a row when there's room */
@media (min-width: 768px) {
  .nav { flex-direction: row; }
}

Base styles are simple. Each breakpoint only adds what the bigger screen needs.

Key ideas

  • Flex container = the parent with display: flex. Its children become flex items.
  • Main axis follows flex-direction (row → horizontal, column → vertical). justify-content aligns along it.
  • Cross axis runs perpendicular. align-items aligns along it.
  • flex-wrap: wrap lets items drop to a new line instead of squishing — the secret to card grids that reflow.
  • flex: 1 1 250px = grow, shrink, start at 250px. Great for responsive columns without media queries.

4. Challenges

Try each one in the playground or in your own file before opening the solution.

Easy Perfectly center one box

Use the playground with 1 item. Center it both horizontally and vertically.

.container {
  display: flex;
  justify-content: center;
  align-items: center;
}
Easy Logo left, links right

A header with a logo and a nav. Push them to opposite ends.

.header {
  display: flex;
  justify-content: space-between;
  align-items: center;
}
Medium Make item 3 fill the leftover space

With 3 items in a row, only the last one should stretch.

.item-3 { flex-grow: 1; }
Medium Stacked on phones, row on tablets

Write it mobile first — no max-width allowed!

.features {
  display: flex;
  flex-direction: column;
  gap: 1rem;
}
@media (min-width: 768px) {
  .features { flex-direction: row; }
}
Hard Card grid with zero media queries

Cards should be 1 per row on phones, 2–4 per row on bigger screens, automatically.

.cards {
  display: flex;
  flex-wrap: wrap;
  gap: 1rem;
}
.card {
  flex: 1 1 250px; /* grow, shrink, min-ish width */
}
Hard Move the sidebar on desktop

On phones the sidebar comes after main content. On desktop, show it on the left — without changing the HTML.

.layout { display: flex; flex-direction: column; }
@media (min-width: 1024px) {
  .layout { flex-direction: row; }
  .sidebar { order: -1; flex: 0 0 250px; }
  .main { flex: 1; }
}

Tip: open DevTools (F12) → Toggle device toolbar (Ctrl+Shift+M) to test real devices.
